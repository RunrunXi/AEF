# AE2 Favorites

![License](https://img.shields.io/badge/license-MIT-blue.svg)

为 AE2 的终端界面添加了收藏物品的功能，可以将物品固定在所有物品最顶端。

> Adds a favorite items feature to AE2 terminals, allowing you to pin items to the very top of the list.

---

## ✨ 功能

- 在 AE2 终端中按 **Shift + 鼠标中键** 固定/取消固定物品
- 被固定的物品会显示在物品列表的最顶端
- 支持所有 AE2 终端类型（ME 终端、合成终端等）

> Press **Shift + Middle Click** to pin/unpin an item in the terminal.  
> Pinned items will always appear at the top of the list.
